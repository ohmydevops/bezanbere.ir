# Bezan Bere — Product

**Principles:** Calm over capable · Action over organization · Restraint over scale

## Rules
- Task limit is user-configurable (default 5, max 20)
- User cannot set limit below current task count
- At limit, adding is blocked with: *«یه کار تموم کن، بعد اضافه کن.»*
- Title only — no deadlines, tags, or notes
- No account — local data, no sync, no tracking

## Stories
| # | Story |
|---|---|
| 1 | See tasks on open (< 1s) |
| 2 | Add task — type + Enter or tap button |
| 3 | Complete task — tap checkbox, animates out |
| 4 | Delete task — swipe right on mobile |
| 5 | Open Settings — change theme mode (light/dark/system) |
| 6 | Set task limit in Settings (1–20, minimum is current task count) |
| 7 | Blocked at current task limit |
| 8 | Works fully offline after first load |
| 9 | Installable to home screen (PWA) |

## UX
- Persian (Farsi), RTL, Vazirmatn font
- Settings modal (gear icon in header)
- Theme modes: Light / Dark / System
- Task limit input in Settings (numeric, LTR for stable number entry)
- Sand color palette, one accent — completion only
- Animations: subtle, 150–300ms, never bouncy

**Non-goals:** No collaboration, AI, reminders, analytics, or import/export.
