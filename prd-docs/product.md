# Bezan Bere — Product

## Why This App Exists

Most Todo apps are built to be managed — tags, deadlines, priorities, projects, sync, AI suggestions. They turn task management into a second job.

Bezan Bere exists for the opposite reason: you have a few things to do today, you want to write them down fast, and you want to stop thinking about the list. The constraint (task limit) is intentional — it forces you to finish before you add more. The name says it all: *بزن بره* — get it done and go.

**Principles:** Calm over capable · Action over organization · Restraint over scale

## User Stories
| # | As a user I can… |
|---|---|
| 1 | See my tasks instantly on open (< 1s), with no login |
| 2 | Add a task by typing and pressing Enter or tapping the button |
| 3 | Complete a task by tapping the circle — it animates out |
| 4 | Delete a task by swiping right on mobile |
| 5 | Tap on a task title to open its detail and edit it |
| 6 | See when a task was added (Shamsi date + time) in its detail |
| 7 | Open Settings and switch between light, dark, and system theme |
| 8 | Set my own task limit (1–20) in Settings |
| 9 | Get blocked from adding more tasks when at the limit |
| 10 | Use the app fully offline after the first load |
| 11 | Install the app to my home screen (PWA) |
| 12 | Get a validation error if my task text exceeds 100 characters |
