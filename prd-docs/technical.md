# Bezan Bere — Technical

---

## Technologies

- **Alpine.js** — reactivity and UI logic
- **Tailwind CSS v4** — styling with dark mode and RTL support
- **Vazirmatn** — Persian font (self-hosted, no Google Fonts request)

## Build

**`package.json` devDependencies:**
```json
{
  "scripts": {
    "build": "npm run build:css && npm run build:copy",
    "build:css": "tailwindcss -i src/input.css -o dist/style.css --minify",
    "build:copy": "cp -r src/index.html src/app.js src/sw.js src/manifest.json src/fonts dist/ && cp node_modules/alpinejs/dist/cdn.min.js dist/alpine.min.js",
    "dev": "tailwindcss -i src/input.css -o dist/style.css --watch & serve dist"
  },
  "devDependencies": {
    "@tailwindcss/cli": "^4.0.0",
    "alpinejs": "^3.14.0",
    "serve": "^14.0.0"
  }
}
```

**Source layout:**
```
src/
  index.html      ← markup + Alpine directives
  app.js          ← Alpine store, IndexedDB logic
  input.css       ← Tailwind directives (@import "tailwindcss")
  sw.js           ← service worker
  manifest.json
  fonts/
    vazirmatn.woff2
```

**Output (`dist/`) — committed and deployed:**
```
dist/
  index.html
  app.js
  alpine.min.js   ← copied from node_modules at build time
  style.css       ← generated by Tailwind CLI
  sw.js
  manifest.json
  fonts/
    vazirmatn.woff2
```

Alpine and `app.js` are loaded as separate `<script>` tags in `index.html` — no bundler needed.

---

## Logic & Storage

Tasks live in **IndexedDB** (`tasks` store). On load, all tasks are fetched and put into an `Alpine.store` — the single source of truth for the UI.

- Add → write to IndexedDB → push to store
- Complete / delete → remove from IndexedDB → remove from store
- 5-task limit enforced in the store before any write
- Theme preference (`light` / `dark`) saved in `localStorage`

---

## Offline

A service worker caches all static assets (HTML, CSS, JS, font) on first load. Every subsequent visit is served entirely from cache — no network needed.

`manifest.json` enables PWA install on mobile and desktop.

---

## SEO

This is a Persian-language app-shell with no crawlable content — traditional SEO doesn't apply.

- `<html lang="fa" dir="rtl">` for correct language signals
- `<meta name="description">` with a short Persian description
- Open Graph tags for link previews (Product Hunt, social sharing)
- `robots.txt` allows indexing of the landing URL
